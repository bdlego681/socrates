Developers

API Reference

Programmatically access your supply chain data, trigger automated purchase orders, and sync analytics directly into your internal tooling.

GET /v1/inventory

List all SKUs

Returns a paginated list of your inventory items, including real-time stock levels and velocity metrics.

Query Parameters

limit
integer		 Limit the number of objects returned (1-100). Default is 50.
status
string		 Filter by stock status: in_stock, low_stock, out_of_stock.
terminal - bash
# cURL Request
curl -X GET https://api.socrates.local/v1/inventory?limit=2 \
  -H "Authorization: Bearer sk_live_..."
// JSON Response
{
  "object": "list",
  "data": [
    {
      "id": "sku_99381",
      "name": "Wireless Earbuds",
      "stock_level": 14,
      "status": "low_stock"
    }
  ]
}
editor - index.js
// Node.js Request
const axios = require('axios');

await axios.post('https://api.socrates.local/v1/purchase-orders', {
  vendor_id: 'ven_48293',
  auto_send: false,
  line_items: [
    { sku_id: 'sku_99381', quantity: 250 }
  ]
}, {
  headers: { 'Authorization': 'Bearer sk_live_...' }
});
// JSON Response
{
  "id": "po_8847291",
  "object": "purchase_order",
  "status": "draft",
  "vendor_id": "ven_48293",
  "total_amount": 4250.00
}
POST /v1/purchase-orders

Create a Purchase Order

Programmatically draft a new Purchase Order. If auto_send is true, it will bypass manual approval and dispatch immediately to the vendor.

Body Parameters

vendor_id
required		 The ID of the vendor to issue the PO to.
line_items
required		 Array containing sku_id and quantity.
auto_send
boolean		 Default false. Set to true to bypass human approval.
GET /v1/vendors/{id}/risk

Get Vendor Risk Profile

Retrieves the live Socrates AI risk analysis for a specific vendor, including lead time deviations and reliability scoring.

terminal - bash
# cURL Request
curl -X GET https://api.socrates.local/v1/vendors/ven_48293/risk \
  -H "Authorization: Bearer sk_live_..."
// JSON Response
{
  "vendor_id": "ven_48293",
  "risk_tier": "high",
  "reliability_score": 86,
  "lead_time_deviation_days": 4.2,
  "recommendation": "route_to_fallback"
}
